# PharmaCentral

PharmaCentral is a pharmacy management system developed using Python and Django. It is designed to simplify and automate daily pharmacy operations such as inventory management, sales tracking, and customer record handling.

## Key Features

- Real-time data entry, retrieval, and monitoring
- Inventory management with minimum stock alerts
- Expiration date tracking with automatic notifications
- Sales and customer data management
- Debtor and administrative record tracking
- Efficient drug search using string searching (name, code, description)

## Smart Monitoring System

The system uses two key approaches:
- Quantity-based alerts: Notifies when stock reaches minimum level
- Expiry-based alerts: Alerts when medicines are expired or near expiry

## Objective

PharmaCentral helps pharmacists manage large volumes of data efficiently, reduce manual workload, and maintain accurate records while ensuring better customer service.
